# ころころ つみき

木の立方体に溝とトンネルが彫られた「玉の道」あそび（cuboro）を、iPad のブラウザで試せる 3D シミュレーター。
個人・家庭用の非公式ツール。

## あそびかた

モードの切り替えはない。画面をなぞるのは、いつでもカメラ。

| やること | 操作 |
|---|---|
| つみきを置く | 下のパレットのつみきを上へ引っぱり出し、置きたい所で離す（見本は指の少し上に出る） |
| 積む | 置いてあるつみきの上で離す |
| 選ぶ | つみきをタップ →「まわす」「けす」が出る（置いた直後は選ばれている） |
| 動かす | 選んだつみきを引っぱる。パレットの上で離すと片づく |
| 玉を転がす | 左の「たま」を引っぱり出す。近くの溝に吸いつくので、そこで離す。「もういちど」で同じ場所からやり直し |
| 中を見る | 「なかを みる」でトンネルが透けて見える |
| カメラ | 画面を1本指でなぞる、2本指で拡大と移動。右下のスティックでも回せる |

玉が止まると、理由が出る（とちゅうで止まった / かべにぶつかった / 上のつみきでふさがっている など）。

## 動かす

```sh
npm install
npm run dev        # 開発（http://localhost:5180）
npm run build      # 本番ビルド → dist/
npm run preview    # dist/ を配信（同じ Wi-Fi の iPad から http://<Mac の IP>:5180）
npm test           # 玉の動きのテスト
```

iPad では Safari で開き、共有 →「ホーム画面に追加」をすると全画面で使える。

## 入っているパーツ

standard（1〜12, MK）、junior、SPEED、TUNNEL、DUO、TRICK、PRO、WAVE、SUB、JUMP、MAGNET の計 97 種。
形は公式サイトの各セットの一覧図から読み取った（読み取りメモ: `docs/research/element-notes.md`）。

実物とちがう所:

- KICK（ハンマーで玉を打ち上げる機構）は入れていない
- MAGNET は形だけ。磁石で宙に浮かせることはできない（下に支えが要る）
- JUMP のトランポリンは、上に落ちた玉がはねるだけの簡易版
- DUO の D15 / D16、junior の KL、SUB の GU は図からの読み取りが不確か
- 溝の幅・トンネルの径・「下の穴」の高さは図からの推定（半径 0.2、下の穴の中心 0.2。1 = 5cm）
- 玉どうしはぶつからない

## しくみ

- `src/parts/catalog.js` … パーツ定義。立方体ごとに「道」（上面の溝 / 中のトンネル / 下面のうら溝）の折れ線を持つ
- `src/sim/track.js` … 置いたパーツの道をつなぐ。道の端の位置がぴったり合ったときだけつながる
- `src/sim/marble.js` … 玉の動き。道の上では重力・摩擦で進み、道が途切れたら空中を飛んで、下の溝に乗る
- `src/view/geometry.js` … 立方体から道の形を引き算して 3D の形を作る
- `src/view/scene.js` / `src/main.js` … 画面と操作

形の確認用: `?grid=<セットid>`（そのセットを並べて表示）、`&xray=1`、`?selftest=1`（操作の自己テスト）。
