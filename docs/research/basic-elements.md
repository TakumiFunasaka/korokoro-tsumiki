# cuboro 基本エレメント調査

調査日: 2026-11-21 / 目的: 子ども向けweb 3Dシミュレーターでの各パーツのモデリング

凡例: **[確認]** = 出典で確認できた事実 / **[二次]** = 非公式の第三者資料で裏づけ（公式ではない） / **[推測]** = 確認できず推測

結論を先に: 公式サイトにはエレメントごとの形状説明・個数内訳・溝やトンネルの寸法は載っていない。形状の一次情報は、公式カタログ（cuboro Australia配布PDF、旧basis/standard）の**アイコン画像**だけだった。それを第三者のOpenSCADモデル（No.2〜No.13）と突き合わせて整理した。

- 第三者の3Dプリント用ツール marble-cube-designer（S10）は「立方体50mm、穴径17mm、玉16mm、上面溝の出口は高さ50mm、トンネル出口は25mm、下面溝は底」と仮定している。ただし作者自身が「市販品との適合は未検証」と書いているので、これは仮定であり事実ではない。

## 2. 「立方体＋側面4面の穴」という抽象化は正しいか

**そのままでは足りない（部分的に正しい）。**

- [確認] 公式は「cuboroのエレメントは、表面と内部の両方に軌道機能を持つ」と説明（S2, S12）。つまり**上面の溝**と**内部トンネル**の2系統がある。「側面の穴だけ」では上面溝が抜ける。
- [確認] カタログのアイコンで、側面の穴は少なくとも「中段」と「下寄り（底に近い）」の2つの高さがある。No.3は下段に別の貫通溝/トンネルがあるように見える。
- [確認] No.7〜10は**傾斜トンネル**（アイコン上、斜めに貫く）。水平な穴の組み合わせでは表せない。
- [確認] No.11・12は**上面の穴から落ちて側面へ出る**縦カーブ。
- [確認] MKは**ビー玉入れ（円筒ポケット）**で、通常の溝・トンネルとは別物。
- 推奨モデル [推測]: 各エレメント = 立方体 + 「経路（path）のリスト」。経路は種類（上面溝直線 / 上面溝カーブ / 水平トンネル / 傾斜トンネル / 縦落下カーブ / 行き止まり）と、入口・出口の面と高さで持つ。

## 3. エレメント一覧（番号ごと）

### 読み方
- 上から見た図: 上辺 = 北。`||` は上面の溝、`==` は内部トンネル（点線で表示）。
- 高さの語: 上面 / 中段 / 下段。中段と下段の実際の高さ（mm）は未確認。
- 形状根拠は、公式カタログ(S2)p.8のアイコン画像を目視で読んだもの [確認:アイコン] と、第三者OpenSCADモデル(S11)の記述 [二次] が一致したものを主に採用。S11は趣味の再現でライセンス記載なし（再利用不可として扱う）。
- 公式カタログ(S2)の機能分類 [確認]: 直線 = No.2,3,4 / 直線・カーブ = No.5,6 / 面変更・カーブ = No.7,8 / 面変更・直線 = No.9,10 / 面変更 = No.11,12。
- 上面の溝が傾斜しているか水平かは、どの出典にも記載なし。S11は水平として作っている。実物は玉が自走するのでトンネル側に勾配があるはず（アイコンのNo.7〜10で傾斜が明確）[推測]。

### No.1 無地キューブ
- [確認] 溝も穴もない土台用（S8, S13）。
- 上面: なし / 内部: なし。
```
+---+
|   |
+---+
```

### No.2 直線溝 + 直線トンネル
- 上面: 北〜南の直線溝（水平）[確認:アイコン, 二次]。
- 内部: 中段を貫通する直線トンネル、溝と平行 [確認:アイコン, 二次]。
- 溝とトンネルは交わらない、独立 [確認:アイコン]。
```
 N
 ||    上面溝 N-S
 ||    (内部 N-S 直線トンネルが重なる位置)
 S
```

### No.3 直線溝 + 直線トンネル + 下段の別トンネル
- 上面: 直線溝 [確認:アイコン]。
- 内部: 中段の直線トンネル + 下段にもう1本、**向きは90度違い** [二次: S11では下段が直交。アイコンでは下側に別の溝/穴が見える]。
- すべて独立 [確認:アイコン, 二次]。
- 下段の穴がトンネルか底面の溝かは断定できない [推測]。

### No.4 十字溝 + 直線トンネル
- 上面: 十字交差の溝（2本が直交）[確認:アイコン]。
- 内部: 中段を貫通する直線トンネル [確認:アイコン]。独立。
```
   |
 --+--
   |
```

### No.5 / No.6 カーブ溝 + 直線トンネル（左右対称）
- 上面: 隣り合う2辺をつなぐ90度カーブ溝（No.5が左、No.6が右）[確認:アイコン, 二次]。
- 内部: 中段の直線トンネル [確認:アイコン]。独立。
- 左右の定義（どちらがNo.5か）はS11基準。向きは回転で吸収できる。
```
 No.5 (S11:左カーブ)
  N
  |_
  .  \_ E ... 溝は北辺→東辺（鏡像がNo.6）
```

### No.7 / No.8 カーブ溝 + 斜めトンネル（左右対称）
- 上面: 90度カーブ溝 [確認:アイコン]。
- 内部: 下段へ**斜めに下りる**トンネル。片側の面は上寄り、反対面は下寄り [確認:アイコン, 二次]。
- 独立。No.7とNo.8は鏡像。
- 出入口の高さ（mm）は未確認。

### No.9 / No.10 直線溝 + 斜めトンネル（左右対称）
- 上面: 直線溝 [確認:アイコン]。
- 内部: 斜めトンネル。一方の面は中〜上寄り、他方は下寄り [確認:アイコン]。
- 独立。No.9とNo.10は斜めの向きが逆（鏡像）。

### No.11 十字溝 + 上面から落ちて側面へ（中段で出る）
- 上面: 十字溝 [確認:アイコン, 二次]。
- 内部: 十字の交点にある穴から**落下**し、縦から横へカーブして側面の穴に出る [確認:アイコン]。
- 上面溝と落とし穴は**つながっている**（十字の中心が穴）[確認:アイコン, 二次S11の十字+Felfele]。
- 出口の高さ: 中段 [二次]。
- 出口の向きは4方向に回転して使う。

### No.12 十字溝 + 上面から落ちて側面へ（下段で出る）
- No.11と同じ上面・落とし穴で、出口が**より下**（底に近い）[確認:アイコン]。
- 落とし穴の深さはNo.11より深い（底近くまで落ちる）[確認:アイコン]。

### MK（マーブルキューブ／ビー玉の保管・ゴール兼スタート）
- 形状: 円筒状の凹み（ビー玉が複数入っている絵）[確認:アイコン]。通常の溝・トンネルは持たない。
- 役割: ゴール兼ビー玉の受け [二次: S7]。
- 凹みの深さ・径は未確認。

### 「No.13」について
- 日本の販売店・ブログは「13種類」と書く（S8, S13, S7）が、番号付きで13番まで載せた出典は見つからなかった。
- 公式カタログ(S2)の中身は **No.1〜12 + MK = 13種類**。これが「13種類」の正体と考えられる [推測]。No.13という番号は確認できていない。
- 第三者S11のNo.13（上面に左カーブと右カーブの2本 + 中段直線）は、standard/basisの外のエレメントで、別物。

### 立方体でない形（半分高さ・ランプ等）
- [確認] 基本セット(standard 16/32/50)には立方体以外はない（出典のカタログ画像上は全て立方体）。
- [二次] juniorには半分サイズ(2.5cm)ブロックがある（S8）。形状詳細は未確認。juniorは「レールやスロープなど玉の動きが見えるパーツが多い」（S14、ブログ記述）。

## 6. 確認できなかった点・推測した点

確認できなかった点
1. 溝の幅・深さ、トンネル直径、トンネル中心の高さ（mm）。公式に記載なし。実物計測が必要。
2. standard 16 / 32 / junior の番号別の個数。公式サイトは合計のみ。説明書PDFやcuboroの本（The Book）にあるはずだが、取得できなかった。
3. junior の全エレメントの形状。半分ブロックの形、レール・スロープの形は未確認。
4. cuboro cubes 単体製品。
5. 上面溝が傾斜しているか水平かの公式記述。
6. 公式のエレメント定義データ（JSON等）やシミュレーター。見つからなかった。GitHubの公開物は全て非公式。
7. 「No.13」の存在。

推測した点
- 形状の細部（No.3の下段が溝かトンネルか、No.7〜10の斜めの角度と出入口の高さ、No.11/12の出口の高さ）は、アイコン画像の目視とS11の一致に基づく。mm単位は不明。
- standard 50のNo.1=19、トンネル径18〜20mm、「13種類=No.1〜12+MK」。
- 画像は低解像度のアイコンなので、No.3・No.7〜10の細部は実物か説明書で要確認。
